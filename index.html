Solar Inverter Register Extraction

PDF 매뉴얼에서 Modbus 레지스터 맵을 바로 추출합니다.

`example/output`의 Python 레지스터 맵 구조를 few-shot 기준으로 사용해 1단계 파싱 결과를 표와 JSON으로 검증할 수 있게 구성했습니다. 2단계는 `RTU_UDP_Systems` 기준으로 H01 매핑과 `READ_BLOCKS`를 확인하고, 3단계에서는 최종 `Register.py`를 생성해 바로 내려받을 수 있습니다.

1
PDF -> 레지스터 맵 파싱
PyMuPDF로 페이지를 이미지화하고 Gemma 비전 모델로 테이블을 JSON화합니다.
2
UDP-서버 레지스터 매칭
`RTU_UDP_Systems/common` 모듈과 definitions를 기준으로 H01 매핑과 READ_BLOCKS를 보여줍니다.
3
Register.py 생성
매칭된 RTU 레지스터 모듈을 기준으로 최종 Python 파일을 생성하고 코드 미리보기를 제공합니다.
